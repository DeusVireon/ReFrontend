## 二、逐文件说明

### 1. `DataAnalyze.tsx`（修改）

- **作用：** 数据分析页根组件，路由 `/analyze` 的懒加载入口。
- **改动要点：**
  - 可滚动布局（`min-h-screen` + `overflow-y-auto`），顶部预留 `h-16` 供后续共用 HeaderBar。
  - 挂载时调用 `loadAnalyzeSnapshot()` 做冷启动；区分 `idle/loading/ready/error`。
  - 组装：字段选择 → 关键指标 → 趋势图 → 明细表。
  - 提供「演示高亮区段 / 清除高亮 / 重新拉取」操作，验证预留高亮接口。

### 2. `models/AnalyzeTypes.ts`（新建）

- **作用：** 跨组件/store 共用的类型与常量。
- **内容：**
  - `AnalyzePayload`、`TimeSeriesPoint`、`SeriesStat`、`HighlightRange`、`LoadStatus` 等类型。
  - `FIELD_META` / `FIELD_GROUPS`：按工艺段分组的字段清单（环境、涂布、转轮、浓缩风、RTO 等）。
  - `SERIES_COLORS`：仅使用 `global.css` 已有色板变量。
  - `DEFAULT_SELECTED_KEYS`：默认勾选字段。

### 3. `stores/AnalyzeData.ts`（新建）

- **作用：** 页面状态中心；数据经 `RestApiInst` 写入，组件不直接解析 JSON。
- **内容：**
  - 快照数据：`series`、`statsByKey`、`updatedAt`、`windowLabel`、`status`、`error`。
  - 视图状态：`selectedKeys`、`highlight`（预留路由/告警跳转写入）。
  - 操作：`toggleKey`、`setGroupKeys`、`setHighlight`、`clearHighlight` 等。
  - `loadAnalyzeSnapshot()`：请求 `/api/analyze`，失败时保持 error 态便于重试。

### 4. `components/AnalyzeSection.tsx`（新建）

- **作用：** 统一区块标题/描述/操作区样式，视觉对齐 Dashboard 的边框与主题色，适配可滚动页面（非全屏绝对定位）。

### 5. `components/FieldSelector.tsx`（新建）

- **作用：**
  - `FieldSelector`：按组全选/取消、单字段切换；列表均 `map` 展开。
  - `SelectedSummary`：展示当前选中字段的最新值与窗口统计。
- **注意：** 订阅 store 时只取稳定引用（如 `selectedKeys`、`statsByKey`），**禁止在 selector 内 `map` 出新对象**，否则会触发 React `useSyncExternalStore` 无限更新（已踩坑并修复）。

### 6. `components/TrendChart.tsx`（新建）

- **作用：** 多字段折线对照；`highlight.start/end` 存在时用 `ReferenceArea` 标出区段。
- **依赖：** 现有 `recharts` + `@/components/ui/chart`，未新增图表库。

### 7. `components/DataTable.tsx`（新建）

- **作用：** 展示窗口内最近 24 个采样点；命中高亮区段的行使用已有 `animate-flash-highlight` / `animate-expand-right`。

### 8. `src/services/RestApi.ts`（新建）

- **作用：** 对照 Dashboard 的 `RTEventMgr` 思路，在请求层统一 `JSON.parse` 与错误日志，成功后把 payload 交给 store handler。
- **API：** `RestApiInst.get(url, handler)` → `{ ok: true } | { ok: false, error }`。

### 9. `src/mocks/analyze-data.ts`（新建）

- **作用：** 写死完整分析快照（约 48 点 × 全字段），数值集中在本文件，便于后续替换为本地文件动态读取。
- **导出：** `MOCK_ANALYZE_PAYLOAD`、`createMockAnalyzePayload()`。

### 10. `src/mocks/handlers.ts`（修改）

- **改动：** 增加 MSW 路由：

```ts
http.get('/api/analyze', () => {
  return HttpResponse.json(createMockAnalyzePayload())
})
```

- **说明：** 分析页走一次性 REST 快照，不走 SSE `/api/event`。其余既有 SSE handler 未改逻辑。

### 11. 目录占位 `readme.md`（删除）

- 已删除：`components/readme.md`、`models/readme.md`、`stores/readme.md`。
- 根目录 `readme.md` 保留，作为编码规范与阶段约束给后续开发参考。

## 三、数据流（简图）

```
浏览器 GET /api/analyze
        ↓
   MSW handlers.ts  →  analyze-data.ts（写死快照）
        ↓
   RestApiInst.get  →  JSON 解析 / 错误处理
        ↓
   AnalyzeData.setPayload
        ↓
   DataAnalyze + components（字段 / 图表 / 表格）
```

高亮路径（预留）：

```
外部（未来：路由 query / 告警点击）
        ↓
   setHighlight({ start, end, attrKeys, source })
        ↓
   TrendChart ReferenceArea + DataTable 行高亮
```

## 四、预览方式

1. 项目根目录执行：`pnpm run dev`
2. 浏览器访问：**http://localhost:3000/analyze**  
   （Dashboard 暂无入口，需手动输入路由）
3. 可选操作：切换字段组、「演示高亮区段」、「重新拉取」验证冷启动与刷新。
